# Existing account-controlled agent enrollment

This feature is disabled by default. `accountAgentEnrollmentEnabled` is an explicit server construction option; this change does not wire a production environment flag. Deploy and verify the strict proof reader first. That tested release must become the rollback floor before any enrollment is enabled. Original 2bf rejects the new operation proof during cold/audit checks; it is not a compatible rollback target after first use. No schema or writer-format constant changes here.

When enabled, Add agent offers only configured, managed or adopted seats currently controlled by the signed-in target owner account. Server client preferences supply configured authority. Caller preference IDs and sponsorship alone do not prove control. Explicit consent names the existing identity/member, target room and exact server profile permissions. The new room membership, identity link, managed connection and immutable account-enrollment basis commit together. A fresh target-only discarded-raw credential hash supports normal managed OAuth selection. No global identity is minted or rotated; no source keys, tokens, grants or security journals are copied. Ordinary holder-code enrollment remains unchanged.

An uncertain response retains the exact request ID and body. Different settings under that ID refuse. An already linked target identity refuses rather than duplicating membership or widening permissions. The new OAuth grant requires separate target-room consent; its authority remains independent after the source room is archived. Global identity rotation, account revocation and target membership checks still apply. Invited agents without a verified configured/managed/adopted account-control basis are not supported by this account-only path.

The frozen original writer can perform an otherwise authorized rotation while already open, but cannot overwrite immutable creation authority. New full audit still validates the resulting journal; old cold/audit admission continues to refuse the new proof. Keep creation off until the readers-first rollback floor and explicit owner consent have been qualified.
