# Current serving representation: review draft

Status: proposal before format or writer-fence edits. No activation or migration is implemented. The source qualification checkpoint is1dac44b86. The eventual endpoint is shared by explicitly initialized synthetic causal rooms and existing rooms after qualified migration. Synthetic success never clears the existing-room blob failure.

## Single authority

Existing messages remains the sole message payload and order authority, retaining exact MESSAGE_PROOF_FIELDS/entity_hash. Existing work_entities remains the sole work payload authority, retaining exact revision/digest/body. Current metadata membership is distinct from entity presence: orphan work rows never become members. Replay units remain temporary derivation inputs and may be erased without damaging an activated room.

Proposed current_room_records columns: room_id TEXT REFERENCES rooms ON DELETE CASCADE; domain TEXT; record_key TEXT; revision INTEGER; payload_bytes INTEGER; payload_sha256 TEXT; payload TEXT; PRIMARY KEY(room_id,domain,record_key). Each domain/key, payload and revision participates in its independent code-owned commitment. A workItems record contains the existing closed {_workEntity:1,id,revision,digest} reference, never a second body. Members, channels, replyRequests, workItems, agentHalts and other current collections use addressed records. Room singleton and collection shape/presence use explicit records; absent, null, empty object and empty array remain distinct. Archive retained IDs become addressed membership records with protected order where order is semantically observed. No eventLog/seen maps are persisted here. Unknown top-level state fails conversion rather than being discarded.

Proposed current_room_head columns: room_id PRIMARY KEY REFERENCES rooms ON DELETE CASCADE; format_version INTEGER=1; sequence INTEGER; event_id TEXT; revision INTEGER; root_sha256 TEXT; counts_json TEXT; control_sha256 TEXT. counts_json has a fixed closed domain schema and only qualified complete counts, including requests and work membership; no count derives from a sparse context. Root proof maintenance must be addressed and bounded: ordinary commands cannot rehash all records. The exact authenticated index layout remains under review; a naive256-level trie exceeds the logical operation budget and is not approved by this draft. Proofs cannot be treated as membership proof merely because a payload self-hash agrees.

rooms.projection becomes only the closed marker {normalizedCurrent:{version:1,headRevision,headHash}}. It contains neither sparse legacy state nor replay-unit references. The marker, current head and independent write proof must agree. Existing readers must recognize the marker and select the normalized route before hydration; treating it as an empty legacy room is corruption.

## Writer and transaction invariants

The persisted format requires real old-writer exclusion. A format marker alone is insufficient. Proposed schema floor45 is justified by current serving representation, independently of unpublished pairing45 work. Both old44 artifacts and already-open44 connections must refuse before any affected-room mutation. New code also needs an internal format writer permit: an accidental new-code legacy serializer must refuse, despite carrying the same schema version. Version values are compatibility fences, never room authorization grants. No live floor change is authorized by this draft.

Store.command retains authentication, session/listener fences, exact command retry precedence, pause/flood guards, authorization, shared event semantics, event/command receipt, work-board sync and fanout transaction. Normalized context selection replaces full room hydration after exact retry. A command either has every addressed and aggregate dependency qualified or refuses explicitly before append. Unsupported commands and over-budget ancestry never fall back to room(). No sparse state is published into the whole-room cache.

Addressed reads prove the requested member/channel/work/message plus required policy and ancestry. Request capacity comes from the protected complete request count. Shared legacy work-default normalization remains public full-state semantics; the current-record transition may avoid global normalization only after complete source qualification. Ordinary reply context owners walk only complete addressed ancestry, preserving nearest-request and different-work barriers. Expiry/retention/global claim conflict and wake eligibility remain explicit dependencies; count alone cannot replace those scans. Any required growing global index must be maintained by the same qualified transition and independently checked in recovery.

Every successful command atomically commits event, command receipt, affected canonical message/work rows, metadata memberships/revisions/proofs, head/counts/root, rooms marker, board effects and durable fanout. Failure at any write rolls all back. An exact command retry returns the original saved event before loading a context. Empty or stale guards must refuse before persistence. Counts change only by admitted effects; deletions and retries do not silently recount damaged data.

## Actual route acceptance

Read-window routes select indexed IDs and scalar sizes before fetching payload. snapshot(full,messageLimit=N) must no longer call room() then trim. Work point reads must select current work membership rather than json_each of old projection. Full room compatibility access must be explicitly bounded or refuse, not secretly assemble unbounded state. Ordinary post, reply, work propose/accept/start/finish, saved result read and same-command retry must run through actual Store.command/read routes with no SELECT full legacy projection, no all-work hydration, no all-retained-messages scan and no full projection rewrite.

Qualification compares full-state and bounded transitions for exact semantics, persisted fields and refusals. Include unloaded old work defaults; complete request count at499/500 with sparse addressed map; duplicate/collision IDs; nearest request ancestry and different-work barriers; expired/revoked permissions; request context stamps; work membership orphans; result evidence immutability; injected entity/metadata/head/receipt/fanout persistence failures; real restart and exact retry. Use small and large finite synthetic rooms with measured statements, rows, bytes and writes. Native/public/assistant/human-push branches must be admitted with complete dependencies or explicitly refused, never disabled silently.

Privacy deletion removes raw affected canonical payload, derived capture generations and old event bodies in the existing privacy transaction. Historical receipts keep pointer/hash facts, never erased text. Account/room deletion must preserve existing privacy and foreign-key behavior.

## Existing room publication and recovery

Qualified migration starts from independently protected current H state with unknown pre-H history provenance. Complete metadata/message/work/retained membership, old proofs, fields, pins and ancestry must qualify before candidate transitions. Prospective tail receipts bind append bytes. Dirty-tail continuation must measure committed net drain against admitted arrivals, not simply eventually finish when writers stop. Final equality compares the same target representation and current authoritative rows; a small final head/version barrier refuses if writers advanced. Publication then atomically selects this endpoint, without new proof stamping on old NULL sources or clearing quarantine.

Whole-store backup/restore must include the new exact schema and complete records/index/head/proofs. Independent recovery recomputes current roots/counts and validates all entity references and order; export/restore cannot certify the old journal gap. Exact current45 artifact restore and new45 artifact restore require separate receipts. Old44 startup/writes against45 source refuse. Optional44 COW schema must be abandoned/removed or explicitly reconciled before floor45; never widen the trigger guard. Rollback to44 requires a separately qualified bounded reverse conversion or exact pre-cutover restore, not an old artifact reading the new marker.
